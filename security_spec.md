# Security Specification - TracksUp

## Data Invariants
1. **User Ownership**: A user document can only be created and modified by the user with the corresponding UID.
2. **Organization Integrity**: Only the owner of an organization can modify its details.
3. **Membership Authority**: Memberships can only be managed by owners/admins of the organization.
4. **Order Confidentiality**: Orders are only visible and modifiable by the retailer and supplier involved.
5. **Product Control**: Only a supplier can manage their own product catalog.
6. **Invite Security**: Invites are generated by organization admins and can only be consumed (accepted) once.

## The Dirty Dozen (Test Payloads)
1. **Identity Theft**: Attempt to update another user's profile.
2. **Shadow Organization**: Attempt to create an organization with someone else's UID as owner.
3. **Privilege Escalation**: Attempt to update own membership role to 'owner'.
4. **Order Hijacking**: Attempt to read an order where neither retailerId nor supplierId matches the user.
5. **Catalog Poisoning**: Attempt to create a product for a supplier organization the user doesn't belong to.
6. **Relational Bypass**: Attempt to create an order referencing a non-existent supplierId.
7. **Invite Spoofing**: Attempt to accept an invite for a different user's email.
8. **State Shortcut**: Attempt to move an order from 'pending' to 'shipped' as a retailer (should be supplier only).
9. **Resource Exhaustion**: Attempt to use a 2MB string as a product name.
10. **Terminal Locked**: Attempt to update a 'delivered' order.
11. **Malicious ID**: Attempt to create a document with an ID containing shell characters.
12. **Blanket Read**: Attempt to list all orders without a retailer/supplier filter.
